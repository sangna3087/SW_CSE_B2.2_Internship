Viewport:Visible area of a webpage.It is a rectangle region where the browser renders and show the content.Anything outside the viewport is not visible to the user. The viewport can be resized by changing the size of the browser window or by using responsive design techniques. The viewport is an important concept in web design and development, as it affects how content is displayed on different devices and screen sizes.

CSS Units:the measurement units used in CSS to define the size, position, and other properties of elements on a webpage.

1.Absolute Units: These are fixed units of measurement that do not change based on the size of the viewport or the user's settings. Examples include pixels (px), inches (in), centimeters (cm), and points (pt).

2.Relative Units: These units are relative to another value, typically the size of the viewport or the user's font size. Examples include percentages (%), em, and rem.
